Gameplay mode

This build does not expose a standalone player launch command yet. The place opens in Aya Studio; use its Play Solo control to start gameplay.

Offline assets

ZIP assets are copied to the local game folder and registered with the asset proxy before the place opens. Use AYA_ONLINE_ASSETS=0 to disable Roblox fallback.

Offline asset collection

Prepare a place.

Convert a binary or XML place to scan its assets, collect accessible references into a local InterceptAssets folder, and download a ZIP with the place and report.

Binary .rbxl files are converted to XML with the local rbx-dom helper; build it once using the setup instructions. Literal asset IDs in supported properties and scripts are scanned; dynamically assembled IDs are not.

What gets included

The ZIP contains the selected place, downloaded assets, an asset manifest, and an error report. Assets that return 401/403 or otherwise fail are listed with their ID, type, and requesting instance path.

Offline use

Extract the ZIP under game/games. Aya’s server checks the matching InterceptAssets folder before Roblox. IDs that could not be collected still need replacement or online access.

Privacy and limits

Only publicly accessible assets are downloaded; no account cookies are requested. The scanner can’t evaluate runtime-generated IDs. Binary conversion uses the locally built rbx-dom helper.

About the project

A port of the Aya engine to Webassembly.

Aya is a robust, customizable, and otherwise heavily modified fork of the Roblox client codebase which was leaked to the public internet around March 2016.

What it includes

Engine and DataModel

The instance hierarchy, Lua VM, physics, scene graph, serialization, and compatibility behavior run as native WebAssembly code.

Studio tools

Qt provides the ribbon, Explorer, Properties, script editor, output, diagnostics, and document workflow.

Browser platform

WebGL, Web Audio, browser storage, local file handling, HTTP, keyboard, mouse, and touch replace native platform services.

Version compatibility

Virtual versions from 2012 through 2016 let places opt into the matching Studio behavior before they are loaded.
